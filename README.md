# tagwerk — bugs and requests

This repository is the tracker for [tagwerk](https://caliora.org/tagwerk/): one markdown file
per day, the note is the truth. **There is no source code here.** The app is built elsewhere;
this repository exists so that reports have somewhere to land and a number to be referred to.

Pull requests are welcome for this README and the issue forms: a typo, a dead link, a clearer
question. The app's source code is not here, so a change to the app itself belongs in an
issue, not a pull request. A pull request may be merged, adjusted, or closed without merging;
opening one carries no promise either way.

## Two things worth knowing

**Everything here is public.** Issues, comments, screenshots and attachments are readable by
anyone, indexed by search engines, and remain in the history after editing. Before you paste a
note, replace private content with made-up text — a bug that reproduces with your real day
reproduces with `- [ ] Buy vegan food` as well. What the app itself does with your data is described
in the [privacy statement](https://caliora.org/privacy?lang=en).

**Write in German if that is easier.** The forms are English so that the tracker stays legible
to everyone; the answer will be in the language you wrote in.

## What happens to a report

It is read. It gets labels and, if something is missing, a question — an issue waiting on an
answer for two weeks is closed, and reopening it takes one comment. Bugs that lose or change
text come first, everything else after. There is no promised turnaround: tagwerk is in beta and
built by one person.

Requests filed here may be built, built differently, or refused. Nothing is owed for an idea in
either direction: filing one grants no claim, and building it carries no payment.
